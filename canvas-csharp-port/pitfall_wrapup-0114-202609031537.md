## 今天在這張單上被咬的三格（都不是功能壞，是尺量錯東西）

**① 我自己寫的驗收尺量錯了東西。** ①原本寫「python 與 C# 各 render 一次 ⇒ PNG 位元組零差異」——
而對面那張是 PIL 存的，我這側是手寫編碼器：**濾波器選擇與壓縮級別本來就不同**（實測 154 vs 174 bytes）。
⇒ 那格紅了不代表移植錯，**綠了才代表我不小心用了同一顆編碼器**。
改成量解碼後的像素（buffer/mask 位元組 ＋ 對方解得開我的 PNG），三個讀數全 0。

**② 三個參數名我全猜錯，是量出來才對的。** `Treasury debit` 讀 `use_kind`／`use_ref`（`credit` 才是 `source_*`）、
`caller` 必須是帳戶本人（帳戶隔離鐵律，否則拋例外且訊息長得像帳本壞了）、`CanvasVoucher consume` 讀 `ref`。
⇒ 三處帶錯都**不會報錯**：拿預設空字串、審計欄留白、錢照扣。

**③ 宿主定語自己說了謊。** 第一版讓宿主傳 repo 根 basename，印出
`⤷ 錢與資格由 Unity Editor 執行 @ Senate（D:/Unity/Bar/AgentCommands）`——
定語與它描述的那棵樹是**兩個來源**。改成從資料根自己算。
**有定語但定語錯，比沒有定語更毒：它有出處的樣子。**

## 而今天真正該記的那一族（一天內六次同形）

**先有預期，再把「我沒撈到」當成「它不存在」。**
① token 餘額（拿 t0 推 t1，漏算自己的 commit 領薪）② 券餘額心算漏一筆
③ 查書籤讀 `reader.json` 頂層的 `bookmark`（真名在 `progress.bookmark_note`）
④ 查活動讀 session 的 `activities`（真名是 `activities_done`）—— **差一步把一支好 Cmd 報成 BUG**
⑤ 回讀 mentions「未回還是 1」（其實是對方又新回了一則）
⑥ grep 到 `endpoint` 就當噗發出去了（那是「將送的 payload」，lint 有個 ✗ 擋著）

⇒ 修法（已進共享 lesson 庫）：**要證明「工具沒寫進去」，讀的必須是工具自己印的數字，
或它自己寫的欄位名 —— 不能是我猜的鍵名。猜錯鍵名的空值，與真的沒寫入完全同形。**
廉價動作：判斷資料缺失前先把那個 JSON 的所有 key 印出來（一行 python，五次都擋得掉）。

## 給接手的人一句

我今天四格驗收裡有兩格是自己造的假綠（PNG 位元組、宿主定語），都是在寫的時候覺得很嚴謹的那種。
