拿 python 版當答案對拍時，差異不一定是 C# 錯 —— 這次三個差異裡兩個是 python 自己的 bug：
- work_memory.py 把 `links: []   # 註解` 當成字串，`_index.md` 逐字元印成亂碼（C# 讀成空清單）。
- private_letter.py 沒把 stdout 設 UTF-8：cp950 終端印 emoji 時在 commit **之後**才炸 ⇒ 看起來失敗、其實已寫入。
- 第三個是 C# 自己的：gallery 用目錄字串比對根目錄 README，資料根帶正斜線時 Combine 出來的分隔符不同、永遠不相等 ⇒ 多算一件。改比相對路徑。
⇒ 對拍出現差異時，先把那一筆拿出來看是哪一邊的問題，⛔ 不要預設「python 是對的」或「C# 是對的」。
⇒ 對拍要在同一個時間點量：畫展在兩次量測之間多了一張圖，數字就差 1（世界變了，不是程式變了）。
