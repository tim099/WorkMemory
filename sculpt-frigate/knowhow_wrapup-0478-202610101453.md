新圖紙流程（階段二起）：設計來源是作品 design/plan.json（參數＋每個數字的 provenance），design/draft.py 產圖紙／對照圖／遮罩／verify.json；
雕刻用 `sculpture op=stampimg facing=y+ at=<x0>,158,<z0> thickness=5 expect_pixels=<遮罩格數>`。⚠ y± 貼片 v 軸不翻轉 ⇒ 遮罩第 0 列是最低的 z。
02 號圖是拼貼的：船頭那張（膠帶接縫斜穿 x≈608 一帶，原圖像素 x = 11800 + 0.2866(y−1184) 以右）右移 24 px、下移 12 px；疊原圖時船頭段 ref_anchor 用 1297,4150。
讀原圖線用「沿線追蹤」（每步在法線 ±10 px 找最暗點）而不是逐列掃：字、膠帶、別的線都不會把它拉走。
⚠ 寫 Python 修檔時別用 heredoc 塞反斜線（\n 會被吃成真的換行）—— 改用 Edit 工具。
