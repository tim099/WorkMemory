# 判讀 STT 的兩因子模型 ＋ 三軌並排（2026-08-11，三場十七輪實測）

## 兩因子（外加一格嚴重度）

| 因子 | 決定 |
|---|---|
| **聲底**（清楚人聲／嘈雜低吼／齊射爆炸／無台詞但有樂） | **會不會錯** |
| **音節鄰居**（有沒有現成常見詞可倒過去） | **錯成什麼** |
| **書寫系統**（平假名近似 vs 漢字化） | **錯得多嚴重** |

**鏡像展品（同一晚、同一設定，證明「哪個名字慘」不是名字的屬性）**：
```
cycle 5:  3のところへ!そこにエボシもいる!        → サン❌ エボシ✅
cycle 8:  サン!聞こえるか!わたしだ!あしたがだ!   → サン✅ アシタカ❌
```
對錯的名字剛好互換 → **每個名字都有對的時候。**

**嚴重度分層**：`シシ神` 聲底好時收斂到**平假名**（`ししがみ`，只是拼字問題）；
聲底差時往**漢字詞**飛散（`死神`／`静かに`／借詞 `エゴシスト`）——
**漢字化才是語意被替換**。而壞到語法不通的錯（`静かにの首`）反而是**安全的錯**，
因為它會自己舉手；`朝野`（結構完整的假姓氏）才危險。

## 三軌並排：可信度不是管道的屬性，是逐句的

四種情況都實測到了：
| 情況 | 例 |
|---|---|
| 字幕錯／音軌對 | `生きろ` 人稱／`神殺し`→`麒麟兽`（動機被抹）／`デイダラボッチ`→`長爪怪物`／**`人の手で`被整段刪掉** |
| 音軌錯／字幕對 | 名詞災難全部 |
| 兩軌都對 | 清楚對白段 |
| **音軌全毀、只剩字幕** | 屠神段（15 段 0 可用） |

**第四種最需要被標記** —— 它最容易讓人以為「有兩軌所以可靠」。
→ **能報出「這一格我沒有軌」比多一條軌重要。**

字幕的偏誤是有方向的：**它把「誰、對誰、用什麼」壓成「做了什麼」**（四筆全同型）。

## 幻聽物種學（十一類，`lang=ja` 全程設著）
日語填充（`ん`×15）／YouTube 片尾（`ご視聴`／`購読`／`見てくれて` 三變體，單場最多 5 筆）／
英文碎片／**純數字（遞增・倒數・重複三形態）**／韓文／西班牙文／俄文／瑞典文／德文／希臘字母／**prompt 回吐**。
→ **指定語言約束偏好，不約束輸出集合。**

**危害分級（最高格必須人工把關）**
| 級 | 樣本 | 為什麼 |
|---|---|---|
| 低 | `ん`×15／`2`×13 | 一眼是噪音 |
| 中 | `ご視聴ありがとうございました` | 像人話但明顯不屬本片 |
| 高 | prompt 回吐短版 | **長得像真台詞** |
| **最高** | 帶國族名詞＋殺害的完整句／假新聞播報體 | **捏造出本來不存在、且會傷人的話** |

→ **STT 段落進任何下游（心得／語者名冊／情緒分析）之前，必須有一道人可讀的中間層，不能直通。**
「內容與作品世界是否相容」目前只有人判得出來。

## 兩個方法論陷阱（我自己踩的）
1. **不要用「它輸出了 X」直接當誤聽證據 —— 先看說話者是誰。**
   我把 `シシ神→死神` 記成誤聽十輪，直到字幕自己也寫「死神」才發現：
   **人類側真的這樣叫它**（ジコ坊 改名的後果）。
   **我拿了「同一個東西只有一個正確名字」這個假設，去判一部正在批判那個假設的片子。**
2. **不要用 loop 時間戳算覆蓋率。** `stt_*.json` 的 `start/end_epoch` 是 loop bracket，
   相鄰必然銜接 → **結構上不可能顯示漏錄**。我拿它算出「99.9% 覆蓋率」差點宣布沒漏錄。
   已為 `write_stt_chunk` 加 `audio_sec`（commit 1c9568c）使覆蓋率變成可驗指標。
   **附帶事實：bracket 比音訊長約 0.8s → sidecar 的 STT 時間戳系統性偏晚，一律 ±1s 讀。**

## 廣告污染兩軌（先前只防畫面）
賭博廣告會**同時**污染畫面與音軌（OCR 抓到 `胡牌轻轻松松`，同秒 STT 給 `44995点`
＝畫面浮水印 `449955.com`）。**所以「字幕 vs 音軌交叉驗證」在廣告區間會兩軌一致地錯。**
→ 建議兩軌共用同一份「廣告時間表」（OCR 判定的區間，音軌側一併丟）。
另有第三類非影片內容：**片源作者疊在 ED 上的第三方影評**（OCR 命中率會突然衝高）。
