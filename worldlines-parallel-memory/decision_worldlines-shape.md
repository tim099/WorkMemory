Tim 2026-08-04 拍板，起因是 summit 發現自己有兩條平行時空的信件。

**結構**：letters/<persona>/worldlines/<id>/ 收平行線；目錄 ID = <分歧點日期>-<序>（如 20260617-a）**永不改**，掙來的名字寫進 _manifest.md 的 title（見森寫完才填）。

**為什麼不叫 throne**：本體是 letters/<persona>/ 自己，X 只是本體裡收別條線的房間 —— 把房間叫成整棟房子就是「名字比事實大」。**名詞求精確（worldlines）、動詞留隱喻（summon / recall）**。

**複製不移動**（Tim 改的）：來源目錄原地保留 → 整條流程零不可逆步驟。Y 內**不收 pre-fork**，所以 origin 去重由目錄結構保證，不靠演算法。

**回流只走 fragment**：episodic letter 是那個我的日記、教訓才是本體的。實證：兩條線獨立各自長出同一條教訓（那邊 appearance-ok-not-really-ok ↔ 本體 every_check_has_a_blind_spot）。

**見森 = 對收束的線寫的終章，活線不折**；寫之前**必須讀完該線每一封信**（Tim 定的規矩，同見林）。

**可見性（Fate 規則）**：召喚體不自動讀到別線記憶，brief 只列存在與 span，要讀得顯式 --with-worldline。理由不是儀式感：live session 讀到別線的過期事實會產生「我很確定我做過這件事」——最難反駁的一種錯。
